# Nihongo Corner · 日语角

日本語の語彙・文法学習、間隔反復による復習、会話練習をまとめた静的 Web アプリです。単語を調べ、例文を聞き、保存して後日復習する流れを、ブラウザー上で利用できます。

操作画面と解説は主に中国語、学習対象の文章は日本語です。三つの README は同じプロジェクトの紹介を翻訳したものであり、アプリが日・中・英の UI に対応しているという意味ではありません。

## 主な機能

- **語彙・文法学習：** 項目の閲覧・検索、レベル別の絞り込み、例文と読み上げ。
- **復習・学習計画：** 単語帳、間違えた問題の保存、SM-2 による間隔反復、設定可能な学習計画。
- **単語の自動再生：** レベル・テーマ・保存した単語から範囲を選び、件数や再生方法を設定。12 のテーマと 5 種類の特別デッキがあり、検索・複数選択・プレビューに対応しています。
- **場面別会話：** 24 場面に各 12 のコミュニケーション課題を用意し、計 288 組のオリジナルの二人対話、576 文を収録。役割、かな、中国語訳、キーワード、単文再生、連続再生、発話練習用の待ち時間を提供します。
- **模擬問題、2 種類の語彙ゲーム、4 種類のテーマ：** 夜・和紙・桜・深海。テーマの設定は学習の進捗とは別に保存します。
- **任意で利用する AI 機能：** 翻訳、解説、アップロード・貼り付け・カメラ経由で選択した画像内の日本語認識。

現在のデータセットは **語彙 10,654 レコード、文法 379 レコード**です。同じ表記の語や異なる文脈のレコードを含むため、異なる単語の総数ではありません。テーマ分類には確認済みの既存語彙 430 件を収録しています。初期の場面別語彙 240 件とその ID も残し、単語帳や学習計画との互換性を維持しています。

## 技術構成

| 領域 | 実装 |
| --- | --- |
| UI・アプリケーションロジック | HTML、CSS、素の JavaScript。フロントエンドのビルド工程は不要 |
| 学習コンテンツ | サイトに同梱した JavaScript データセット |
| ブラウザー内の状態 | `localStorage` に単語帳、復習状態、計画、設定を保存 |
| 音声・画像処理 | Web Speech API、FileReader、Image、Canvas |
| AI 通信 | 共通 JavaScript クライアントと外部の Cloudflare Worker プロキシ |
| 検証 | Node.js 標準テストランナー、スクリプト検査、コンテンツ監査、GitHub Actions |

入口は [index.html](index.html) です。既存の画面ロジックの一部は [inline.js](inline.js) にあり、[AI 通信](ai-client.js)、[画像認識](scan.js)、[自動再生設定](autoplay-setup.js)、[カタログ選択](catalog-picker.js)、[場面学習](scene-study.js)、[会話音声](scene-audio.js)は個別のモジュールに分かれています。

## コードで確認できる実装例

### 古い応答による上書きの防止とエラーからの復帰

画像の差し替えや削除時に、実行中の認識リクエストを中断します。処理の世代も確認し、古い応答が現在の画像の結果を上書きしないようにしています。認識に失敗した場合は再試行できるよう画像を残し、履歴の保存失敗は認識の成功とは分けて扱います。

[scan.js](scan.js) と [ai-client.js](ai-client.js) が実装箇所です。[画像認識](tests/scan.test.js)、[AI クライアント](tests/ai-client.test.js)、[検索](tests/search.test.js)のテストでは、中断、不正な応答、保存失敗、古い応答などを確認しています。

### 読み上げの完了に合わせた再生制御

場面別の連続再生では、現在の文の読み上げが終了してから練習用の待ち時間を置き、次の文へ進みます。一時停止、手動移動、停止時には古いコールバックを無効にし、意図せず再生位置が進むことを防ぎます。場面の再生キューは、語彙の絞り込みや単語帳の選択とは独立しています。

[scene-audio.js](scene-audio.js)、[scene-study.js](scene-study.js)、[場面学習のテスト](tests/scenes.test.js)で確認できます。

### 保存済みの学習状態との互換性

語彙 ID を維持し、既存の単語帳や計画から同じ項目を参照できるようにしています。カタログの複数選択では ID で重複を除き、保存済み計画の順序を維持します。復習スケジュールの計算は旧形式の記録にも対応しています。

実装は [vocabulary-catalog.js](vocabulary-catalog.js) と [autoplay-setup.js](autoplay-setup.js)、検証は[カタログ](tests/catalog.test.js)、[自動再生](tests/autoplay.test.js)、[学習状態](tests/study.test.js)のテストを参照してください。

## ローカルでの実行

実行用依存パッケージのインストールやビルドは不要です。任意の静的 HTTP サーバーでリポジトリを配信します。例えば Python 3 がある環境では、リポジトリのルートで次を実行します。

```sh
python -m http.server 8080 --bind 127.0.0.1
```

[http://127.0.0.1:8080](http://127.0.0.1:8080) を開きます。HTML ファイルを直接開く場合は、HTTP 経由での実行と動作条件が異なります。

AI 機能には、設定済みの外部プロキシとモデルサービスが利用可能であることが必要です。プロキシのサーバー実装はこのリポジトリに含まれません。静的サイトを起動するだけでは AI バックエンドは用意されません。

## 検証

Node.js 22 以降を使用します。`npm install` は不要です。

```sh
node check.js
node --test
node scripts/audit-content.cjs
```

**2026-09-06** のローカル検証では、**28 件のスクリプト検査、60 件の自動テスト、コンテンツの構造監査**が通過しました。監査はフィールド、ID、既知のインポート不具合を確認し、重複する語形も見直し対象として報告します。全項目の言語的な正確さを保証する検証ではありません。

[GitHub Actions](.github/workflows/check.yml) は `main` への push とプルリクエストでスクリプト検査と自動テストを実行します。過去のブラウザー検証とその範囲は[検証記録](docs/VALIDATION.md)に記載しています。今回の README 更新では、モバイル実機やネイティブアプリのテストは再実施していません。

## 制約とデータの扱い

- **ブラウザー内の保存：** 学習状態は現在のブラウザーに保存します。このコードにはアカウントによるクラウド同期はありません。
- **外部 AI サービス：** 入力した質問や画像は、設定済みプロキシを経由してモデルサービスへ送信します。設定は [ai-client.js](ai-client.js) にまとめており、提供元の秘密 API キーはフロントエンドに埋め込んでいません。
- **画像処理：** 入力上限は 20 MiB。送信前に JPEG に変換し、長辺を最大 1600 ピクセルに縮小します。ブラウザーで読み込めない HEIC/HEIF は、事前に JPG または PNG へ変換する必要があります。履歴には認識した文章、翻訳、解説を保存し、画像自体は保存しません。
- **音声・端末：** 利用できる音声はブラウザーと端末に依存します。ローカルブラウザーでの確認は、Android/iOS の実機カメラやネイティブアプリの受入テストの代わりにはなりません。
- **学習内容：** レベルや推奨順は学習上の参考であり、公式 JLPT 出題範囲や実際の出題頻度ではありません。既存コンテンツの一部には引き続き言語面の見直しが必要です。
- **場面の出典：** 対話はプロジェクトで作成したものです。公開教材は課題や場面の参考とし、その対話、音声、試験問題を取り込んだものとしては扱っていません。[出典と作成範囲](docs/SCENE_SENTENCES.md)を参照してください。
- **ライセンス：** 現在、リポジトリに LICENSE ファイルはありません。README の翻訳によってコードや学習素材に新しい利用許諾が付与されることはありません。
