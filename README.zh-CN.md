# Nihongo Corner · 日语角

一个用于日语词汇、语法、间隔复习和会话练习的静态 Web 应用。学习者可以在浏览器中完成查词、听例句、收藏和后续复习，把查询与持续学习连接起来。

应用界面和解说以中文为主，学习材料为日语。三份 README 是同一项目的介绍译文，不代表应用已经提供中、日、英三语界面。

## 主要功能

- **词汇与语法：** 浏览、搜索、等级筛选、例句和语音播放。
- **复习与学习计划：** 单词本、错题收藏、SM-2 间隔复习和可配置的学习计划。
- **自动背单词：** 按等级、主题或生词本选择范围，设置数量和播放选项。目录包含 12 个主题、5 个语言专项，支持搜索、多选和预览。
- **场景会话：** 24 个场景，每场景 12 个交流任务，共 288 组原创双人对话、576 句。提供双方角色、假名、中文、关键词、单句试听、连续播放和跟读停顿。
- **模拟题、两款词汇游戏与四种主题：** 夜色、和纸、樱花、深海。主题偏好单独保存，不与学习进度混用。
- **可选 AI 功能：** 翻译、解说，以及上传、粘贴或通过相机选择图片后的日语文字识别。

当前数据集包含 **10,654 条词汇记录和 379 条语法记录**。词汇记录中有重复词形和不同语境，不能理解为互不重复的单词数量。精选主题收录 430 条已核对的旧词条；早期场景词库的 240 条记录及其 ID 继续保留，兼容已有单词本和计划。

## 技术与结构

| 部分 | 实现方式 |
| --- | --- |
| 界面与应用逻辑 | HTML、CSS、原生 JavaScript，无前端构建步骤 |
| 学习内容 | 随网站提供的 JavaScript 数据集 |
| 浏览器状态 | 使用 `localStorage` 保存收藏、复习状态、计划与偏好 |
| 语音与图片 | Web Speech API；FileReader、Image 和 Canvas |
| AI 请求 | 统一 JavaScript 客户端与外部 Cloudflare Worker 代理 |
| 验证 | Node.js 内置测试运行器、脚本检查、内容审计与 GitHub Actions |

页面入口是 [index.html](index.html)。现有页面逻辑有一部分位于 [inline.js](inline.js)，[AI 通信](ai-client.js)、[图片识别](scan.js)、[播放设置](autoplay-setup.js)、[目录选择](catalog-picker.js)、[场景学习](scene-study.js)和[会话音频](scene-audio.js)分别有独立模块。

## 可结合代码查看的实现案例

### 防止旧结果覆盖与失败恢复

替换或移除识图图片时，会取消当前请求；同时通过处理代次检查，防止旧请求返回后覆盖新图片的结果。识别失败时保留图片以便重试，历史保存失败也与识别成功分开处理。

实现见 [scan.js](scan.js) 和 [ai-client.js](ai-client.js)。[识图测试](tests/scan.test.js)、[AI 客户端测试](tests/ai-client.test.js)和[搜索测试](tests/search.test.js)覆盖取消、异常响应、存储失败与过期响应等情况。

### 等待语音结束再推进播放

场景连播先等待当前句朗读结束，再经过跟读停顿后进入下一句。暂停、手动切换和停止会使旧回调失效，避免它们意外推进队列。场景队列独立于词汇筛选和单词本选择。

实现与验证见 [scene-audio.js](scene-audio.js)、[scene-study.js](scene-study.js)和[场景测试](tests/scenes.test.js)。

### 兼容已有学习状态

保留稳定的词汇 ID，使已有收藏和计划仍能找到相应词条。目录多选按 ID 去重，已保存的学习计划保留顺序，复习调度兼容旧记录。

实现见 [vocabulary-catalog.js](vocabulary-catalog.js) 和 [autoplay-setup.js](autoplay-setup.js)；对应验证见[目录测试](tests/catalog.test.js)、[播放设置测试](tests/autoplay.test.js)和[学习状态测试](tests/study.test.js)。

## 本地运行

无需安装生产依赖，也无需构建。使用任意静态 HTTP 服务打开仓库。例如安装 Python 3 后，在仓库根目录运行：

```sh
python -m http.server 8080 --bind 127.0.0.1
```

访问 [http://127.0.0.1:8080](http://127.0.0.1:8080)。直接双击 HTML 文件不等同于通过 HTTP 运行。

AI 功能依赖已配置的外部代理和模型服务可用。本仓库不包含代理服务端实现，仅启动静态网站并不会同时提供 AI 后端。

## 验证

使用 Node.js 22 或更新版本，无需 `npm install`：

```sh
node check.js
node --test
node scripts/audit-content.cjs
```

**2026-09-06** 本地验证通过：**28 项脚本检查、60 项自动化测试及内容结构审计**。内容审计检查字段、ID 和已知导入缺陷，同时报告重复词形供进一步审查；它不能证明每条词汇与语法的语言学准确性。

## 限制与数据处理

- **浏览器存储：** 学习状态保存在当前浏览器中；当前代码没有基于账号的云同步。
- **外部 AI 服务：** 提交的查询和图片会经已配置的代理发送到模型服务。[ai-client.js](ai-client.js) 集中管理配置，前端没有内嵌提供商密钥。
- **图片处理：** 输入上限为 20 MiB；上传前转成 JPEG，长边不超过 1600 像素。浏览器无法解码的 HEIC/HEIF 文件需要先转成 JPG 或 PNG。历史记录保存识别文字、翻译和解析，不保存图片本身。
- **语音与设备：** 可用声音取决于浏览器和设备。本地浏览器检查不能替代 Android/iOS 实机相机和原生应用验收。
- **学习内容：** 等级和推荐排序属于学习参考，不是官方 JLPT 考纲或实际考试频率统计。部分旧内容仍需进一步语言校订。
- **场景来源：** 场景对话由项目自行编写，公开教学资料用于参考交流任务与语境，不将其对话、音频或试题作为导入内容。详见[来源与原创边界](docs/SCENE_SENTENCES.md)。
- **许可：** 当前仓库没有 LICENSE 文件；这些 README 译文不构成对代码或学习材料的新使用授权。
