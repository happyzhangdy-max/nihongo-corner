| 问题 | 修复 |

| 拍照识图返回 404：旧模型无可用端点 | 改用现有代理已验证可用的 Gemini 2.5 Flash |

| 存储不足导致成功结果被清掉；历史清空后可能复活 | 存储故障与识别成功分开处理，同步清空内存历史 |
| 搜索在 WebView 兼容代码中重复绑定；旧请求覆盖新结果 | 使用可替换的事件绑定，中止旧请求并忽略过期结果 |

| SM-2 读取了错误的字段，复习间隔一直是 1 天 | 读取 interval/repetitions/ef，兼容原缩写字段 |
| touchmove 误调用拖动结束回调 | 正确区分移动和结束事件，并移除监听器 |
