## 词句与选择

- 新增 240 条场景词汇与表达、240 个原创例句；均有词头读音、中文释义、完整日文例句、对应假名和中文译文。
- 其中 70 条词头与读音已在原词库出现，但例句不同。新增记录内部的「目印」「現在地」分别用于问路和紧急求助，保留各自语境。
- 旧 10,414 条词汇及所有原 ID 保持不变。新增 ID 固定为 20001–20240，全库现为 10,654 条。
- 分类支持搜索名称、日文词、假名和中文释义；可跨分类方式多选。已选范围用标签显示，可单独移除，并预览前三条完整词句。
- 多选取并集，按记录 ID 去重。选择某场景和包含它的上位主题不会重复同一记录；不同语境的同词头记录仍可能各出现一次。
- 新的空选择禁用开始按钮；旧空分类的“全部词库”含义迁移为明确标签。旧分类字符串仍可按原范围匹配。
- 自动背单词与词库“按分类背”共用目录；词库仍支持等级与词性筛选。搜索结果不再把未经核对的旧分类显示成可靠主题。

## 实现与验证

- `scene-vocab.js` 保存新增词句；紧跟 `data.js` 加载并合并，确保搜索、详情、收藏、复习、计划和游戏能解析新 ID。
- `vocabulary-catalog.js` 保存稳定分类 ID、场景归属和已核对词条 ID；不依据错误的旧 category 批量推断新主题。
- `catalog-picker.js` 负责分类浏览、搜索、多选与预览；播放设置与队列仍由 `autoplay-setup.js` 管理。
- `node check.js`：24 个脚本及资源引用通过；`node --test`：53 项测试通过；全库结构检查通过。
- 隔离 Chromium 验证 320、390、1280 像素宽度，无横向溢出；验证空选择、搜索无结果、跨分类去重、预览、键盘标签移除、场景例句播放、收藏和计划词序。
- 词库按分类浏览验证了词性、24 个场景、12 个主题和 5 个专项；显示数量与实际词条一致。

## 边界

旧 category 存在系统性错分，不能作为新主题的依据。尚未逐条确认的词汇继续保留在全部词库中，不声称已完成全库语义归类。旧语言专项的所有内容也未在本轮重新逐句审校。

新增词句经过作者自审与独立交叉审校；等级只表示本站学习难度参考，不是官方分级。医疗、防灾条目用于语言沟通，不包含诊断、药物剂量或具体应急操作指导。

本轮统一自动背单词和词库分类入口。两个小游戏的旧分类菜单仍待单独整理；题库的 category 表示题型，与词汇分类无关。实体手机、iOS Safari 和原生 APK 未在本轮验证。
