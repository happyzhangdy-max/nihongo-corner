# 场景句子与参考来源

更新：2026-09-05。

## 为什么场景以句子为主

本页目标是完成订位、问路、改预约等交流任务，因此使用“场景 → 任务 → 我方表达 → 对方回应”，关键词只作辅助。判断依据包括国际交流基金《いろどり》的 Can-do 目标，以及文部科学省“つながるひろがる”按生活场景组织的表达。语义主题与语言专项仍用于词汇学习。

## 内容与匹配规则

24 个场景，每场景 12 组双人短对话，共 288 组、576 句。每组有稳定任务 ID、角色与情境、完整日文、对应假名、中文、最多两个关键词。第一句必须是学习者可直接说的话，第二句须回应当次任务；叙述过去做过什么不能代替完成任务的表达。对方回应是可能的示例，时间、金额、窗口安排不表示通用规则。医疗、药店与防灾部分只训练询问、说明与确认。

所有对话是本站原创。下列资料用于核对场景与交流任务，没有批量转载教材、题目或音频。参考资料提供场景框架，新增情境并不表示在所列课文中逐项出现。免费在线阅读不等于允许再分发。浏览器语音是设备提供的合成语音，没有使用教材录音。

- [Tatoeba](https://tatoeba.org/en/)是后续可评估的授权句库，本轮没有导入任何句子或音频。若将来导入，须逐句保留作者、链接、授权与必要署名。
