# 场景句子与参考来源

更新：2026-09-05。

## 为什么场景以句子为主

本页目标是完成订位、问路、改预约等交流任务，因此使用“场景 → 任务 → 我方表达 → 对方回应”，关键词只作辅助。判断依据包括国际交流基金《いろどり》的 Can-do 目标，以及文部科学省“つながるひろがる”按生活场景组织的表达。语义主题与语言专项仍用于词汇学习。

## 内容与匹配规则

24 个场景，每场景 6 组双人短对话，共 144 组、288 句。每组有稳定任务 ID、角色与情境、完整日文、对应假名、中文、最多两个关键词。第一句必须是学习者可直接说的话，第二句须回应当次任务；叙述过去做过什么不能代替完成任务的表达。对方回应是可能的示例，时间、金额、窗口安排不表示通用规则。医疗、药店与防灾部分只训练询问、说明与确认。

所有对话是本站原创。下列资料用于核对场景与交流任务，没有批量转载教材、题目或音频。免费在线阅读不等于允许再分发。浏览器语音是设备提供的合成语音，没有使用教材录音。

## 来源使用边界

- [《いろどり》课程说明](https://www.irodori.jpf.go.jp/about.html)用于 Can-do 和任务框架；[使用条件](https://www.irodori.jpf.go.jp/privacy.html)不应理解为任意改编复制教材。

- [まるごと＋](https://marugotoweb.jp/ja/)与[东京外国语大学言语模块](https://www.coelang.tufs.ac.jp/modules/ja/dmod/lp/)用于核对交流功能与角色，不复制其完整对话。

- [Tatoeba](https://tatoeba.org/en/)是后续可评估的授权句库，本轮没有导入任何句子或音频。若将来导入，须逐句保留作者、链接、授权与必要署名。

本地只读核对了《软件工程师日语速成会话》的学习材料、赴日 IT 面试资料及其他日语课程、词句资源。它们支持识别工作和在日生活任务；授权不明的正文、音频与完整路径不随仓库发布。本地资源的存在不代表本轮所有场景都来自书籍；市役所、银行、邮寄、药店与防灾主要参考上述官方公开场景。

## 兼容与验证

场景数据、播放状态和设置独立于 VOCAB、收藏及复习 ID。旧场景词 ID 保留，不改写用户已有收藏和学习计划。进入旧的场景选择时转入相应句子页，并移除已迁移的词汇场景筛选，避免返回时循环跳转。旧全部词库占位符遇到明确分类时让位于具体分类，显式“全部词库”模式仍然有效。

内容完整性、任务唯一性、全文假名及队列边界有自动检查；自然性和角色对应经过编写自审及独立复核。此范围不代表对全站历史词汇、所有语法或母语音频进行了重新认证。
